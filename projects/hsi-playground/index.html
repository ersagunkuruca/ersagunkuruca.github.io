WebGPUColorGraphicsVisualization

A playground for reasoning about HSI — hue, saturation and intensity on linear RGB. It puts CSS HSL, HSI using mean intensity, and a luminance-based HSI variant side by side, and draws the tilted slice through the RGB cube in 3D so you can see what each “intensity” actually selects.

Built with WebGPU; needs a WebGPU-capable browser (Chrome/Edge 113+, Safari 26, Firefox 141+).
