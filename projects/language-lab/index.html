Language Lab

Experiments in new programming-language ideas: a projectional language whose source is a tree with names kept on the side, and functions that run in any direction.

Two connected prototypes.

Projectional. The program is stored as a tree of nodes with opaque IDs. Names, comments, operator symbols, infix or prefix, nested calls or a chain of temporaries: all of that is a view each person picks, so the same code can read as maths, as plain words or as Lisp. There is no parser on purpose. The editor in the browser works directly on the tree, refuses edits that would add a type error and says why, and has a node view where dragging a variable onto an input wires it in.

Invertible functions. A “function” is a relation: ports and the equations between them, with no fixed inputs or outputs. Pick which ports you know and the solver writes an ordinary program for the rest. It isolates one unknown at a time, eliminates linear blocks exactly, tears nonlinear loops and finds every root in range, and follows every branch of a multi-valued inverse while marking one answer as canonical.
